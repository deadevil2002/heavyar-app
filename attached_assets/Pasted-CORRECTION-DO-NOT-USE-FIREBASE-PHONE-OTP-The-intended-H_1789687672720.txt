CORRECTION — DO NOT USE FIREBASE PHONE OTP.

The intended Heavyar authentication model is:

ONE Firebase account
ONE Firebase UID
ONE password

The user's mobile number is only an ALTERNATE LOGIN IDENTIFIER linked to the same account.

The user must be able to sign in with either:

1. Email + existing password
OR
2. Mobile number + the SAME existing password

There must be NO OTP login.

Do NOT enable Firebase Phone Authentication.
Do NOT use SMS OTP.
Do NOT create a second Firebase identity for the phone number.
Do NOT duplicate users.

1. CANONICAL AUTH MODEL
==================================================

Firebase email/password remains the canonical authentication credential.

Each user may also have:

normalizedPhone = +9665XXXXXXXX

linked uniquely to the same Firebase UID.

The phone number is a login alias only.

It is NOT:
- a second Firebase account
- a verified identity credential
- an OTP authentication provider

==================================================

email
+

3. PHONE + PASSWORD LOGIN
==================================================

Implement secure phone-alias login through the Worker.

Flow:

1. User enters:
   phone number
   password

2. Worker:
   - normalizes the Saudi phone number
   - resolves the protected phoneOwners mapping
   - identifies the linked Firebase UID/email internally
   - NEVER returns the linked email to the client

3. Worker verifies the supplied password against Firebase's official password authentication endpoint.

4. Confirm the authenticated Firebase localId/UID exactly matches the expected UID from phoneOwners.

5. After successful Firebase password verification:
   issue an authenticated Firebase session/custom-token flow for that SAME UID.

6. Mobile completes Firebase sign-in for the same user.

The password must be:
- used only transiently for Firebase verification
- never stored
- never logged
- never written to Firestore
- never included in analytics/audit data

No custom password database.
