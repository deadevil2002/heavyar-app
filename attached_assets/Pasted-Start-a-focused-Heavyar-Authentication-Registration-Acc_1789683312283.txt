Phone:

==================================================
10. PASSWORD RESET DELIVERY
==================================================

Review the current Firebase password reset implementation.

We want a more professional email-delivery flow.

Preferred architecture:

1. User requests password reset.
2. Worker securely resolves the Firebase account.
3. Backend generates an OFFICIAL Firebase password-reset link.
4. Heavyar sends the reset email using the existing server-side Resend integration.
5. User opens the official reset link.
6. Firebase validates the action code.
7. User chooses the new password.
8. Password is changed through Firebase Auth.

Do NOT create our own password-reset token system.

Do NOT store passwords.

Do NOT log passwords or reset URLs.
