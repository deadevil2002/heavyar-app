==================================================
BUG CONFIRMED
==================================================

On desktop browsers, especially Arabic RTL, the admin sidebar/navigation is completely missing.

The dashboard content renders, but the navigation menu is off-screen.

Mobile drawer works.

The current Sidebar implementation contains this class logic when the drawer is closed:

rtl:translate-x-full
ltr:-translate-x-full
md:translate-x-0

This appears to allow the RTL transform to remain active on desktop and push the fixed sidebar outside the viewport.

File:
admin/src/components/Sidebar.tsx

Layout also reserves desktop sidebar space using:
md:ms-64

File:
admin/src/components/Layout.tsx

So desktop content expects a persistent sidebar while the sidebar itself is being translated off-screen.
