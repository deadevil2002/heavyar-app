- build tooling

==================================================

- push notifications
- in-app notification inbox
- read/unread state
- notification categories
- notification deep links
- server-authoritative event generation

- future notification preferences

3. DEVICE TOKEN MANAGEMENT
==================================================

Implement secure FCM token registration.

Device tokens must be bound to:

- Firebase UID
- installation/device identifier if appropriate
- platform
- createdAt
- updatedAt
- lastSeenAt
- active/revoked state

Protect against:

- one user registering tokens for another user
- stale tokens accumulating forever
- duplicate tokens
- invalid token reuse

Users may only manage their own device tokens.
