## Top 10 remediation order

1. DP-001 — restore Account Integrity with shared token cache plus batchGet and a stable 503 contract.
2. DP-004 — remove the systemic per-Firestore-call OAuth exchange from all Admin paths.
3. DP-009 — add and deploy the missing staff claim-sync composite index.
4. DP-005 — place a measured budget on Dashboard aggregates and plan counters.
5. DP-006 — prevent infrastructure failures from becoming valid zero metrics.
6. DP-007 — batch generic campaign notification-preference reads.
7. DP-003 — resolved in P2-C; retain query/read-budget and outside-first-page regression tests.
8. DP-010 — create indexed driver discovery dimensions/projection.
9. DP-011 — remove the 101-history availability cliff without weakening overlap safety.
10. DP-012 — make Early Access unseen counts exact/bounded without 20-second 100-row scans.

## Recommended next phase boundaries

P2-C is narrowly limited to DP-003 and preserves direct canonical-source ownership. The next separate search scalability phase is DP-010 public driver discovery; it must not reuse Admin-only semantics without preserving `driverEligibility` and market filters.
